# @fyrlabs/dead-drop

The `ddrop` command: start the runtime, expose a local server or directory, connect to a remote exposure, discover peers, inspect transports, and read logs and metrics. Every command takes `--json`.

Part of [dead-drop](https://github.com/fyrlabs/dead-drop) — a transport-agnostic runtime for distributed applications. See the repository README for the full picture, and `docs/` for the architecture, security model and delivery guarantees.

## Install

```bash
npm install @fyrlabs/dead-drop
```

Requires Node.js 20.11 or newer.
