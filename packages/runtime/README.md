# @fyrlabs/dead-drop-runtime

The agent that runs on a machine: workspaces, transport plugin loading, HTTP and static exposures, peer discovery, and a Unix-socket control plane. Embed it in a process, or run it through the `ddrop` CLI.

Part of [dead-drop](https://github.com/fyrlabs/dead-drop) — a transport-agnostic runtime for distributed applications. See the repository README for the full picture, and `docs/` for the architecture, security model and delivery guarantees.

## Install

```bash
npm install @fyrlabs/dead-drop-runtime
```

Requires Node.js 20.11 or newer.
